# Dataset Information

## Dataset Name
DataCo SMART Supply Chain Dataset

## Source
Kaggle: https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis

## Main File
`dataco_supply_chain/DataCoSupplyChainDataset.csv`

## Additional Files
- `DescriptionDataCoSupplyChain.csv` — descriptions of the dataset's columns.
- `tokenized_access_logs.csv` — clickstream/access-log data; not used in the primary experiments.

## Notes
The dataset files are stored locally and are excluded from Git version control. Download the dataset from the source above to reproduce the experiments.
